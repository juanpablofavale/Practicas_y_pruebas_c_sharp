# Pruebas y notas sobre mis avances con C# con los módulos de Microsoft Learn

## Forma de trabajo

Se plantea el desarrollo inicial con C# para mejorar mis habilidades y conocimientos como scripting.
La forma más sencilla de ejecutar los archivos con extensión cs (*.cs) es ejecutando por línea de comandos 'dotnet ./Prueba.cs'.
Para tales ejecuciones será necesario tener instalado .Net 10.
Esto permite ejecutar las líneas desarrolladas en c# sin necesidad de contar con un proyecto completo ni la compilación directa (aunque internamente se esté compilando la aplicación).
